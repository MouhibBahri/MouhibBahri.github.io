Selected projects

Company project, source not public

Persistent AI agent memory

Jul 2026·Designer and builder·Twigbit

Cross-session, self-tuning RAG memory for a production agent. It improves with use and fades when stale.

How it works4
  • 1024-d embeddings, int8-quantized into libSQL F8_BLOB columns through a custom Drizzle type.
  • Ranked by (1 − d) × 0.95^days, plus automatic injection of the top memories at session start.
  • Weights tuned by agent feedback (EWMA, α = 0.3) and a nightly decay with a ~69-day half-life.
  • Nightly garbage collection, and recalled memories are treated as data, never as commands.

ResultAdopted as the memory model for 4 other agents at the company.

  • Turso / libSQL
  • Drizzle

University capstone Repository

Distributed Dataset Repository

Feb – May 2026·Team of 4·~31% of hand-written code

A replicated chunk store for AI datasets in Go and gRPC, inspired by the Google File System and designed for 50+ GB datasets.

How it works4
  • 64 MiB chunks streamed in 1 MiB CRC32-checked blocks, replication factor 3 via chain replication.
  • I built the master’s failure handling: heartbeats every 10 s, a 15 s timeout, automatic re-replication.
  • Chained acks: fsync, wait for downstream, seal, ack upstream. A client ack means every replica persisted.
  • A failure-injection suite kills a node and corrupts a chunk in Docker, then checks the rebuilt copy’s SHA-256.

ResultPresented to course faculty. Team: Amir Mallek, Roua Ayadi, Moncef Koubaa and me.

  • Go
  • gRPC
  • Protocol Buffers
  • BoltDB
  • Docker Compose
