# mouhibbahri.github.io

Personal portfolio of Mouhib Bahri, served by GitHub Pages from `main`.

- `src/content.mjs`: all copy, in English and French
- `src/template.mjs`, `src/figures.mjs`: page markup and the SVG diagrams
- `assets/`: CSS, JS, self-hosted fonts, images
- `node build.mjs`: regenerates `index.html`, `fr/index.html` and `404.html`

Edit the content, run the build, commit the generated files.

Theme: the palette tokens are at the top of `assets/css/site.css`. Alternatives can be previewed with `?palette=cobalt`, `forest`, `crimson` or `amber`.

Fonts: Newsreader and IBM Plex (SIL Open Font License).
